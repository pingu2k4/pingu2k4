# Asset sources

- Native skill tiles, including .NET and pnpm: [Skill Icons](https://github.com/tandpfun/skill-icons). Original brand backgrounds retained. These tiles are stored locally to keep the displayed set stable.
- Blazor, SQL Server and Railway marks: [Devicon](https://github.com/devicons/devicon). Marks placed in tiles matching Skill Icons' 256 × 256 canvas and 60-unit corner radius.
- Azure Functions: [Azure icon collection](https://github.com/benc-uk/icon-collection).
- esbuild: [project favicon](https://github.com/esbuild/esbuild.github.io/blob/main/src/scripts/favicon.svg).
- Linear: [official brand assets](https://linear.app/brand). The white logomark is embedded unchanged in a matched tile with Linear's blue background.
- WPF and MAUI: custom window/device and wordmark artwork; not official product logos.
- Header: custom SVG artwork for this profile.
- Personal statistics: [GitHub Stats Extended](https://github.com/stats-organization/github-stats-extended), using its [official Action](https://github.com/stats-organization/github-readme-stats-action).
- Contribution and organisation summaries: [GitHub Profile Summary Cards](https://github.com/vn7n24fzkq/github-profile-summary-cards), fetched from its public API during daily updates. Failed refreshes retain the committed cards.

Technology and project names and logos identify tools used; they do not imply endorsement.
